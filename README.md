# TaskFlow — Gerenciador de Tarefas

O TaskFlow é uma aplicação web desenvolvida para organizar tarefas de maneira simples e prática. O projeto foi criado como parte do meu aprendizado em Análise e Desenvolvimento de Sistemas (ADS), com o objetivo de praticar os fundamentos do desenvolvimento web.

## Funcionalidades

- Cadastro de tarefas com título e descrição.
- Marcação de tarefas como concluídas.
- Possibilidade de reabrir tarefas concluídas.
- Exclusão de tarefas.
- Filtros para visualizar todas as tarefas, pendentes ou concluídas.
- Painel com contadores de tarefas.
- Barra de progresso que indica a porcentagem de tarefas concluídas.
- Armazenamento das tarefas no navegador utilizando LocalStorage.

## Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização, layout e responsividade.
- **JavaScript:** lógica da aplicação, manipulação do DOM, eventos e gerenciamento das tarefas.
- **LocalStorage:** persistência dos dados no navegador.

## Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. Comece a cadastrar e gerenciar suas tarefas.

Não é necessário instalar dependências para executar a versão atual do projeto.

## Armazenamento dos dados

As tarefas são armazenadas no LocalStorage do navegador. Isso permite que os dados continuem disponíveis após atualizar a página, no mesmo navegador e ambiente.

Os dados não são sincronizados entre dispositivos e não utilizam um banco de dados ou servidor nesta versão.
